# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/wbgcoding/AdMutify/security/advisories/new) instead. Include the AdMutify version, your Windows version and the steps to reproduce.

You will get an answer as soon as possible. Once a fix is released, the advisory is published together with it.
