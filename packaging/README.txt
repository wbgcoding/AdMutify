AdMutify
Mutes (or lowers) the Spotify desktop app while an ad plays and restores the old volume afterwards.
Start AdMutify.exe. The tray icon opens the menu and the settings.
Portable: portable.txt next to AdMutify.exe keeps settings, state and logs in this folder.
Installed copy: settings in %APPDATA%\AdMutify, logs in %LOCALAPPDATA%\AdMutify\logs.
Uninstall: delete this folder (portable) or use the uninstaller (installed copy).
AdMutify makes no network connection and does not change Spotify.
